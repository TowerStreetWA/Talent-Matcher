3. CANONICAL / VARIANT MAPPING
====================================

For this taxonomy:

- Use **canonicalTitle** for the most generic/common name.
  - Example: canonicalTitle "Site Reliability Engineer" with variants ["SRE", "Senior Site Reliability Engineer", "Platform Reliability Engineer"].
- Use **variants** for:
  - abbreviations (CIO, CTO, CISO, SRE, DBA),
  - minor spelling variations,
  - level variations (Junior/Senior/Lead) when they are obviously the same function.

Add **seniority** when clear:
- “Junior Software Engineer” → seniority: "junior"
- “Senior DevOps Engineer” → "senior"
- “Head of Engineering” → "exec"

Add **tags** for technical domains where useful:
- ["cloud", "aws", "azure"] if you have domain tags later,
- ["security", "infosec", "soc"] etc.

4. INTEGRATION INTO SEARCH/TAGGING

Wire this taxonomy into the same pipeline as other industries:
