# Billing (Stripe) — detailed reference

- Replit Stripe integration (`stripe` + `stripe-replit-sync`; credentials via connector API in `lib/stripeClient.ts` — NOT env vars). Managed webhook `/api/stripe/webhook` (raw body, registered BEFORE express.json). Webhook-synced data lives in the `stripe` DB schema (read-only). `tenant_billing` caches per-tenant state, refreshed from `stripe.subscriptions` on GET /billing/subscription — never from checkout redirects. Trials: `payment_method_collection: if_required` (no card).
- Access gate (`middlewares/billing.ts`): trialing/active/past_due → full; otherwise reads OK, writes 402; billing + auth routes always reachable; checkout/portal admin+ only. Frontend: `billing-gate.tsx` intercepts all mutation 402s via react-query MutationCache → global trial-prompt dialog; return-path via sessionStorage `vm_checkout_return`.
- Pricing: single source of truth `lib/billing/plans.ts` — GBP, 7-day trials: Core £120/user/mo, Professional £220/user/mo self-serve; Business is `contactOnly` ("Team rollout pricing" — no public price/checkout; GET /billing/plans redacts its price IDs/amounts; £450 bundle + £95/extra-seat rates stay internal for quotes + existing subs, `computeBusinessSeatBreakdown` unchanged). Annual = 10× monthly. Pilot offer copy (5-seat Professional £1,100/mo) on /pricing + landing.
- `LEGACY_PLAN_ALIASES`: starter/solo→core, team→professional, pro_agency/enterprise→business; demo tenant keeps its old USD subscription (plan changes via Stripe portal — cross-currency checkout is rejected → 400).
- Price IDs resolved from `stripe.prices` via product `metadata.plan_key` + price `metadata.billing_interval`; Business extra-seat prices carry `metadata.price_component=additional_seat`. Checkout accepts `seats` (default = plan seatMinimum; Business sends 2 line_items).
- GET /billing/plans is public (mounted before requireAuth); `/pricing` page is public + in-app; shared UI in `components/plan-cards.tsx`; public landing page `pages/landing.tsx` at unauthed `/` (Talent Matcher branding, demo mailto `sales@talentmatcher.ai`).
- Seed products: `pnpm --filter @workspace/scripts exec tsx src/seedStripeProducts.ts` (idempotent); `src/devStartTrial.ts` starts a dev trial for demo tenant.
